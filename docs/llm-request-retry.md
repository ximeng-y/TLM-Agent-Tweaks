# 请求失败自动重试

对应 Issue #5。本文说明自动重试的固定规则、与已有流式回退的分工、以及与其他附属 mod 的兼容边界。

## 解决的问题

模型站点在高峰期会返回 429 或 5xx。此前这类响应会直接走 TLM 的失败回调：气泡消失、聊天栏报错、玩家需要重新发起对话，而多数情况下等几秒重发就能成功。本功能在同一轮对话内自动重发。

## 固定规则

规则写死，**不提供配置项**，只有 `retry.enabled` 一个总开关（默认 `true`）：

| 项目 | 取值 |
| --- | --- |
| 每次请求的最大额外重试次数 | **2 次**（不含首次发送） |
| 每次重试前的固定等待 | **5 秒** |
| `Retry-After` 响应头 | **忽略** |
| 退避策略 | **无**（不做指数退避，不加抖动） |
| 触发重试的状态码 | **429、500、502、503、504** |
| 429 的处理 | 一律重试，**不区分**短期限流与配额耗尽 |
| 不重试的失败 | 其他 HTTP 错误、编码错误、工具执行错误 |

等待时长与站点积压放行间隔取同一个常量：一次重试正好对应一个站点额度周期，避免出现比站点恢复更快的无效请求。

## 与流式回退的分工

这是两条独立路径，不要混淆：

| | 触发条件 | 是否受 `retry.enabled` 控制 | 是否计入 2 次额度 |
| --- | --- | --- | --- |
| **状态码重试** | 收到 429/5xx | 是 | 是 |
| **非流式回退** | 流式传输中途断开（连接中断、超时、缺终止标志）、或站点明确不支持 `stream` | **否**，始终生效 | 否，单独一次 |

回退一旦发生，本轮后续尝试都保持非流式，不再切回流式；回退之后若再遇到可重试状态码，仍可继续消耗 2 次额度。

## 站点排队

站点返回 429 后，该站点进入 5 秒冷却。冷却期间**尚未发出**的请求（含其他女仆、其他玩家的）会排队，冷却结束后按 FIFO 放行，积压期间相邻放行至少间隔 5 秒；已经发出的请求不受影响、不被取消。因此实际发送时刻可能晚于「失败后 5 秒」，这是刻意的：重试潮会把一个正在限流的站点推向更深的限流。

队列清空后立即恢复正常直发，不留下永久节流。不同站点状态完全独立。

## 整轮时间预算

一次逻辑对话（玩家一次提问，或一次自言自语/互聊，含其全部工具续接轮次）共享 **240 秒**的固定预算，不可配置。工具续接复用同一个回调对象，因此取到的是同一个预算实例，**不会**被每一轮工具调用重置。

预算耗尽时本轮请求被作废，并以一条超时失败走到 TLM 的失败回调（玩家能看到原因，而不是气泡一直转）。同一女仆在此期间新发起的对话有各自的预算，不受影响。

## 玩家可见行为

重试期间只更新等待气泡，**不**输出聊天栏错误、**不**提前调用失败回调：

- 状态码重试：`请求失败，5 秒后重试（第 1/2 次）`；
- 429 限流：`请求过于频繁，5 秒后重试（第 1/2 次）`；
- 站点排队：`站点繁忙，正在排队等待发送…`；
- 流式回退：`流式响应中断，正在改用普通模式重试…`。

只在请求**确实存在**等待气泡时替换，没有气泡的内部请求（如静默关键词规划）保持静默，不会凭空新建气泡。重试仍会向站点发出真实请求，**因此可能重复计费**。

## 关闭方式

`config/tlmagenttweaks-common.toml`：

```toml
[retry]
	# 请求失败自动重试总开关（服务端权威）
	enabled = true
```

设为 `false` 后不再重试、不再做站点冷却，流式断流改用非流式重发的行为不受影响。

## 兼容边界

- **只改本 mod**：不修改 Self-Talk 与 MIMO-TTS 的任何代码、配置或产物。
- **Self-Talk**：Self-Talk 在 `LLMCallback.onSuccess` / `onFailure` 的 HEAD 注入以标记「玩家聊天结束」。本 mod 的预算清理落在同一个 `LLMCallback` 类上，但采用不同方法名的私有方法注入，两者互不干扰；重试期间不调用 `onFailure`，因此不会让 Self-Talk 提前解除「玩家聊天进行中」标记。工具续接的实际行为与未装本 mod 时一致：`addToolResult` 返回调用者自身，续接复用同一个回调对象。
- **MIMO-TTS**：TTS 走 `LLMCallback.onSuccess` 之后的独立链路，重试发生在 TTS 之前，两者不重叠。
- **重试与工具有序性**：重试不重新执行工具。工具执行错误不进入重试范围（与规则表一致）。
